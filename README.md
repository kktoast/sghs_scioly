# Science Olympiad — Find Your Events

A single-page website where high school students browse the Division C Science
Olympiad events, pick the ones they want to compete in, add teammates for each,
and submit a final list.

**Live site:** [`[https://kktoast.github.io/sghs_scioly/]`](https://kktoast.github.io/sghs_scioly/)

## What it does

- Shows all 23 Division C events, grouped by the five science disciplines, with
  a short description and a link to the official rules for each.
- Lets students search, filter by discipline, or show only their picks.
- Students enter their name, then tap **Add** on any event to build a lineup.
- For each event they can add teammates (up to that event's team limit) or
  choose to enter it solo.
- On submit, each student's picks and teammates are saved to a Google Sheet,
  and every student can submit only once.
